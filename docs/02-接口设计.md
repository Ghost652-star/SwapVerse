## 1. 说明

小程序端与服务端之间采用 HTTP 接口通信，数据格式为 JSON，接口地址统一以 `/api` 开头。需登录的接口在请求头中携带 token：

```
Authorization: Bearer <登录时返回的 token>
```

## 2. 统一返回格式

所有接口返回同一结构：

```json
{ "code": 0, "message": "ok", "data": { } }
```

请求成功时 code 为 0，所需数据置于 data 中；请求失败时 code 为非 0 值，message 为可直接展示给用户的说明，data 为 null。前端依据 code 判断处理方式，不依据 message 内容判断。

## 3. 错误码

| code | HTTP 状态 | 含义 | 示例 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 401 | 401 | 未登录或登录失效 | 未携带 token |
| 404 | 404 | 资源不存在 | 物品已被删除 |
| 1001 | 400 | 物品状态不允许当前操作 | 申请本人发布的物品、物品已被锁定 |
| 1002 | 403 | 无操作权限 | 修改他人发布的物品、普通用户调用管理接口 |
| 1003 | 400 | 交换状态不允许当前操作 | 重复接受、确认已取消的交换 |
| 1004 | 400 | 参数校验失败 | 未填写标题、驳回未填写理由 |
| 1005 | 403 | 账号已被禁用 | 禁用账号尝试登录 |

1001 与 1003 的区分依据：涉及物品状态的返回 1001，涉及交换状态的返回 1003。

## 5. 主要接口约定

### 5.1 分页参数

物品列表、留言列表与收藏列表采用同一组分页参数：pageNum 表示页码，从 1 开始，默认 1；pageSize 表示每页条数，默认 20。

返回结构：

```json
{ "code": 0, "message": "ok",
  "data": { "total": 6, "pageNum": 1, "pageSize": 20, "list": [ ] } }
```

### 5.2 发布物品

请求：

```json
{ "title": "高等数学同济第七版", "categoryId": 1, "condition": "八成新",
  "expect": "想换线性代数教材", "description": "笔记不多，无缺页",
  "imageList": ["/uploads/20261105/a.jpg", "/uploads/20261105/b.jpg"] }
```

返回：`{ "code": 0, "data": { "id": 7, "status": 0 } }`，status 为 0 表示待审核。

### 5.3 发起交换

请求：

```json
{ "targetGoodsId": 4, "offeredGoodsId": 1, "message": "我的台灯九成新，想换你的手环" }
```

返回：`{ "code": 0, "data": { "exchangeId": 12, "status": 0 } }`

失败示例：`{ "code": 1001, "message": "物品状态不允许当前操作：不能申请交换自己发布的物品", "data": null }`

### 5.4 确认完成

单方确认：`{ "status": 1, "finished": false }`
双方确认：`{ "status": 4, "finished": true }`

### 5.5 审核

请求：`{ "action": "reject", "reason": "图片与描述不一致，请补充实物照片" }`
返回：`{ "goodsId": 7, "status": 5 }`

## 6. 权限与可见性

| 情形 | 处理结果 |
|---|---|
| 未登录调用需登录的接口 | 返回 401，小程序跳转登录页 |
| 普通用户调用管理接口 | 返回 403 + 1002 |
| 修改或删除他人发布的物品 | 返回 403 + 1002 |
| 非物品所有者执行接受操作 | 返回 403 + 1002 |
| 查询物品列表与详情 | 无需登录，仅返回已上架物品 |
| 联系方式 | 仅在交换处于进行中或已完成状态下对双方显示 |
