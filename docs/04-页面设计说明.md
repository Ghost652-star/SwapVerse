## 2. 主要页面布局

### 2.1 首页

页面自上而下分为三部分：搜索框、分类导航与物品列表。分类导航采用横向滚动方式，包含“全部”与 8 个分类。物品列表为双列布局，每个卡片依次显示封面图、标题（最多两行）、期望换得的物品、成色与发布时间。

列表无数据时显示“还没有物品，去发布第一个吧”；加载过程中显示占位块，避免出现空白页面。

### 2.2 物品详情

页面上部为图片轮播区，支持左右滑动，右下角显示当前图片序号。中部依次显示标题、成色、期望换得的物品、描述及发布人信息（头像、昵称、完成次数）。留言区位于中部下方，每条留言显示头像、昵称、内容与时间，回复内容缩进显示。

页面底部为固定操作栏，左侧为收藏按钮，右侧为“申请交换”按钮。操作栏固定于页面底部，不随内容滚动。

### 2.3 发布

图片上传区采用九宫格布局，最后一格为添加按钮，选满 9 张后不再显示添加按钮。其下依次为标题输入框、分类选择、成色选择、期望换得的物品输入框与描述输入框。成色选项为全新、九成新、八成新、七成新及以下四类。

提交按钮固定于页面底部。表单校验未通过时，提示文字显示于对应输入项下方，并在提交时定位至第一个错误项。

### 2.4 我的交换

页面顶部为“我发起的”与“我收到的”两个标签。每条记录显示对方物品封面、标题、状态标签、留言内容与操作按钮。不同状态下的可用操作如下：

| 状态 | 我发起的 | 我收到的 |
|---|---|---|
| 待处理 | 取消 | 接受、拒绝 |
| 进行中 | 取消、确认完成 | 取消、确认完成 |
| 已拒绝 / 已取消 / 已完成 | 无 | 无 |

取消与拒绝操作须弹出确认提示后再执行。

### 2.5 管理端

页面分为待审核列表、分类管理与数据统计三部分。待审核记录显示图片、标题、描述与发布人，提供“通过”与“驳回”两个按钮；点击驳回后弹出输入框填写理由，理由为空时确认按钮不可点击。统计部分显示用户数、物品数、交换数与完成率四项数据。

## 3. 页面跳转关系

1. 首页 → 点击物品卡片 → 详情 → 点击“申请交换” → 交换页（携带目标物品编号）→ 提交后返回详情；
2. 发布 → 提交成功 → 跳转“我发布的”并提示等待审核；
3. 个人中心 → 四个功能入口 → 分别进入我的交换、我发布的、我的收藏、我的留言；
4. 我的留言 → 点击某条留言 → 跳转至对应物品详情；
5. 管理端 → 审核完成后自动刷新列表。

## 4. 界面规范

| 项目 | 规范 |
|---|---|
| 主色 | #07c160，用于主要按钮与选中状态 |
| 危险色 | #ee0a24，用于删除、取消、驳回等操作 |
| 状态色 | 待处理 #fa8c16、进行中 #1989fa、已结束 #909399 |
| 正文字号 | 28rpx |
| 辅助字号 | 22 至 26rpx，用于标签与时间 |
| 按钮字号 | 30rpx |
| 圆角 | 卡片 16rpx，按钮 44rpx |
| 间距 | 取 4 的倍数，常用 8、16、24、32rpx |
| 页面背景 | #f5f6f7，卡片为白色 |
| 图片比例 | 统一按 4:3 裁切填充 |

公共样式统一写入 app.wxss，包括卡片、主按钮、危险按钮、状态标签与空状态五类，各页面直接引用，不重复定义。

## 5. 交互约定

1. 提交类按钮在请求期间置为不可点击状态并显示加载提示，避免重复提交；
2. 图片接口返回相对路径，页面显示时统一拼接服务器地址；
3. 状态文字与颜色统一取自状态对照文件，页面中不直接以数字判断状态；
4. 标题最多显示两行，超出部分省略，避免挤压下方按钮；
5. 删除、取消、驳回等不可恢复的操作，执行前弹出确认提示。
